TEORIE

Ce este un subprogram?

Definiție Un subprogram (funcție) este un bloc de cod cu nume, care poate primi date de intrare (parametri), execută un set de instrucțiuni și poate returna un rezultat. El poate fi apelat de mai multe ori din program, evitând repetarea codului.

Gândește-te la un subprogram ca la o rețetă de bucătărie: o scrieri o dată și o folosești ori de câte ori ai nevoie, cu ingrediente diferite de fiecare dată.

Structura unui subprogram în Python

Antet (header)
def nume(param1, param2):
Corp (body)
instrucțiuni indentate
Apel (call)
rezultat = nume(val1, val2)
exemplu generalpython
def salut(nume, varsta):          # antet: def + nume + parametri
    mesaj = f"Bună, {nume}! Ai {varsta} ani."   # corp
    return mesaj                      # returnare rezultat

# apel:
text = salut("Ana", 16)
print(text)                          # Bună, Ana! Ai 16 ani.

Concepte cheie

Concept Explicație Exemplu Python
parametri formali Variabilele din definiție – „locuri rezervate" def calc(x, y):
parametri efectivi Valorile reale transmise la apel calc(5, 3)
return Trimite un rezultat înapoi la apelant și oprește funcția return x + y
variabilă locală Există doar în interiorul funcției temp = 0 (în corp)
variabilă globală Definită în afara funcțiilor, vizibilă peste tot PI = 3.14 (înainte de def)

Subprograme fără return vs. cu return

Procedură (fără return) Execută acțiuni (afișează, modifică ceva). Nu produce o valoare.
def afiseaza_patrat(n):
    print(n * n)
Funcție (cu return) Calculează și returnează o valoare care poate fi folosită.
def patrat(n):
    return n * n

Subprograme predefinite utile în Python

Funcție Ce face Exemplu
abs(x) Valoarea absolută a lui x abs(-7) → 7
round(x, n) Rotunjire la n zecimale round(3.567, 2) → 3.57
int(x) Conversia la întreg (trunchiază) int(3.9) → 3
float(x) Conversia la număr real float("3.14") → 3.14
math.sqrt(x) Rădăcina pătrată math.sqrt(25) → 5.0
len(lista) Numărul de elemente len([1,2,3]) → 3
min(lista) Minimul dintr-o colecție min([4,1,7]) → 1
max(lista) Maximul dintr-o colecție max([4,1,7]) → 7
sum(lista) Suma elementelor sum([4,1,7]) → 12
Reține! Pentru a folosi math.sqrt trebuie să scrii la începutul programului: import math
EXEMPLE REZOLVATE

Să vedem cum funcționează

Exemplul 1 – Funcție simplă cu return

Scrieți o funcție care primește două numere reale și returnează distanța dintre ele pe axa numerelor.

exemplu1_distanta.pypython
def distanta(a, b):
    # distanța pe axă = valoarea absolută a diferenței
    return abs(a - b)

# testăm funcția
d1 = distanta(3, 8)
d2 = distanta(-5, 2)
print(f"Distanța dintre 3 și 8: {d1}")     # 5
print(f"Distanța dintre -5 și 2: {d2}")   # 7
Parametrii a și b sunt variabile locale – există doar în interiorul funcției.

Exemplul 2 – Funcție cu validare a parametrilor

Scrieți o funcție care calculează aria unui dreptunghi. Dacă dimensiunile sunt invalide (negative sau zero), funcția afișează un mesaj de eroare.

exemplu2_arie.pypython
def arie_dreptunghi(lungime, latime):
    if lungime <= 0 or latime <= 0:
        print("Eroare: dimensiunile trebuie să fie pozitive!")
        return None        # ieșim din funcție fără rezultat
    return lungime * latime

# apeluri
print(arie_dreptunghi(5, 3))    # 15
print(arie_dreptunghi(-2, 4))   # Eroare: dimensiunile...

Exemplul 3 – Funcție care apelează altă funcție

Proiectare modulară: funcția ipotenusa folosește funcția distanta_euclidiana.

exemplu3_modular.pypython
import math

def patrat(x):
    return x * x

def ipotenusa(cateta1, cateta2):
    # teorema lui Pitagora: c² = a² + b²
    suma_patrate = patrat(cateta1) + patrat(cateta2)
    return round(math.sqrt(suma_patrate), 2)

# triunghi dreptunghic 3-4-5
c = ipotenusa(3, 4)
print(f"Ipotenuza: {c}")    # Ipotenuza: 5.0
Principiu cheie – modularitate Descompunerea în subprograme mici face codul mai ușor de înțeles, de testat și de modificat. Fiecare funcție face un singur lucru, bine definit.

Exemplul 4 – Funcții predefinite pentru colecții

exemplu4_colectii.pypython
def raport_note(note):
    """Generează un raport statistic pentru o listă de note."""
    n = len(note)
    if n == 0:
        return "Lista de note este goală."
    media = round(sum(note) / n, 2)
    return (f"Elevi: {n} | Min: {min(note)} | "
            f"Max: {max(note)} | Medie: {media}")

note_clasa = [7, 9, 10, 6, 8, 7, 5, 9]
print(raport_note(note_clasa))
# Elevi: 8 | Min: 5 | Max: 10 | Medie: 7.62

print(raport_note([]))
# Lista de note este goală.

Exercițiul 1 – Răspunsuri corecte (10 puncte)

• Numele funcției: temperatura_medie

• Parametrii formali: t1, t2, t3

• Parametrii efectivi: 22.5, 18.0, 25.3

• Variabilele locale: medie

• Ce returnează: media rotunjită la 1 zecimală a celor trei temperaturi

• Valoarea afișată: 21.9 (calcul: (22.5+18.0+25.3)/3 = 65.8/3 ≈ 21.933... → 21.9)

Grilă: câte 2p pentru fiecare identificare corectă (parametri 2p total dacă ambii corecți).

Exercițiul 2 – Soluție (15 puncte)

def este_par(n): return n % 2 == 0 print(este_par(4)) # True print(este_par(7)) # False print(este_par(0)) # True

Punctaj: 8p definiția corectă + 4p apeluri corecte + 3p afișare corectă.

Observație: 0 % 2 == 0 → True; zero este număr par – mulți elevi greșesc aici!

Exercițiul 3 – Soluție (20 puncte)

def salariu_net(brut): if brut < 3000: impozit = 0.10 else: impozit = 0.16 return round(brut * (1 - impozit), 2) print(salariu_net(2500)) # 2250.0 print(salariu_net(3000)) # 2520.0 print(salariu_net(4500)) # 3780.0

Punctaj: 10p logica condițională corectă + 5p calculul corect + 5p apeluri și afișare.

Atenție: condiția este brut < 3000 (nu ≤), altfel 3000 lei ar fi taxat cu 10% în loc de 16%.

Exercițiul 4 – Soluție (25 puncte)

def cost_bilete(nr_elevi, pret_bilet): return nr_elevi * pret_bilet def aplica_reducere_grup(cost, nr_elevi): if nr_elevi >= 20: return cost * 0.90 return cost def cost_total_excursie(nr_elevi, pret_bilet): bilete = cost_bilete(nr_elevi, pret_bilet) bilete_reduse = aplica_reducere_grup(bilete, nr_elevi) transport = 120 return round(bilete_reduse + transport, 2) def cost_per_elev(total, nr_elevi): return round(total / nr_elevi, 2) total_18 = cost_total_excursie(18, 25) print(total_18) # 570 print(cost_per_elev(total_18, 18)) # 31.67 total_24 = cost_total_excursie(24, 25) print(total_24) # 660 print(cost_per_elev(total_24, 24)) # 27.5

Punctaj: 5p funcția cost_bilete + 6p funcția aplica_reducere_grup + 7p funcția cost_total_excursie + 4p funcția cost_per_elev + 3p testare corectă.

Eroare frecventă: reducerea se aplică doar la costul biletelor, nu și la taxa fixă de transport.

Exercițiul 5 – Soluție (20 puncte)

def analiza_temperaturi(temp_list): if len(temp_list) == 0: return "Lista de temperaturi este goală." n = len(temp_list) minim = min(temp_list) maxim = max(temp_list) medie = round(sum(temp_list) / n, 1) return f"Zile: {n} | Min: {minim}°C | Max: {maxim}°C | Medie: {medie}°C" temp = [18.5, 22.0, 31.0, 28.4, 12.5, 19.0, 25.6] print(analiza_temperaturi(temp)) # Zile: 7 | Min: 12.5°C | Max: 31.0°C | Medie: 22.4°C print(analiza_temperaturi([])) # Lista de temperaturi este goală.

Punctaj: 5p tratare caz gol + 5p utilizare len/min/max/sum + 5p format mesaj + 5p testare.

Nota: media = (18.5+22+31+28.4+12.5+19+25.6)/7 = 157/7 ≈ 22.4.

Exercițiul 6 ★ – Soluție (10 puncte bonus)

def adauga_nota(note, nota_noua): if 1 <= nota_noua <= 10: note.append(nota_noua) print(f"Nota {nota_noua} adăugată.") else: print(f"Nota {nota_noua} este invalidă (trebuie să fie între 1 și 10).") def media_elev(note): if len(note) == 0: return "Nicio notă înregistrată." return round(sum(note) / len(note), 2) def promovat(note): m = media_elev(note) if isinstance(m, str): return False return m >= 5 def afiseaza_catalog(note): print(f"Note: {note}") print(f"Medie: {media_elev(note)}") status = "Promovat" if promovat(note) else "Nepromovat" print(f"Status: {status}") note_elev = [] adauga_nota(note_elev, 8) # Nota 8 adăugată. adauga_nota(note_elev, 6) # Nota 6 adăugată. adauga_nota(note_elev, 4) # Nota 4 adăugată. adauga_nota(note_elev, 11) # Nota 11 este invalidă. adauga_nota(note_elev, 7) # Nota 7 adăugată. afiseaza_catalog(note_elev) # Note: [8, 6, 4, 7] # Medie: 6.25 # Status: Promovat
