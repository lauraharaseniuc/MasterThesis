Modelul liniar de organizare a datelor

O listă este o colecție de elemente așezate unul după altul. Două cazuri particulare, foarte importante, se deosebesc prin regula de acces la elemente — adică pe unde adăugăm și de unde scoatem:

  • Stiva (Stack) — acces LIFO: Last In, First Out (ultimul intrat, primul ieșit).
  • Coada (Queue) — acces FIFO: First In, First Out (primul intrat, primul ieșit).

1. Stiva — LIFO 🥞

Ideea

Imaginează-ți o stivă de farfurii: pui farfurii una peste alta și, când ai nevoie, o iei mereu pe cea de deasupra — adică ultima adăugată. Nu poți scoate o farfurie din mijloc.

Operațiile de bază:

  • push — adaug un element în vârf;
  • pop — scot elementul din vârf;
  • top/peek — văd vârful fără să-l scot.
Exemple din viața reală
  • Butonul „Undo / Anulează ultima acțiune” dintr-o aplicație.
  • Butonul „Înapoi” din browser.
  • Teancul de cărți de pe birou.

2. Coada — FIFO 🎟️

Ideea

Imaginează-ți rândul la casa de bilete de la cinema: cine ajunge primul este servit primul. Te așezi la coadă și aștepți să-ți vină rândul; oamenii ies din față, intră prin spate.

Operațiile de bază:

  • enqueue — adaug un element la coadă (în spate);
  • dequeue — scot elementul din față;
  • front — văd primul element din rând.
Exemple din viața reală
  • Cererile de suport tehnic, tratate în ordinea sosirii.
  • Coada de tipărire la imprimantă.
  • Mașinile oprite la semafor pe o stradă cu sens unic.

💻 Implementare în Python cu clasa list

Stiva

stiva = []

stiva.append(10)   # push
stiva.append(20)
stiva.append(30)

varf = stiva[-1]    # top → 30
x = stiva.pop()    # pop → scoate 30

print(stiva)        # [10, 20]

append() și pop() lucrează la același capăt → comportament LIFO.

Coada

coada = []

coada.append("Ana")    # enqueue
coada.append("Bogdan")
coada.append("Carla")

primul = coada[0]      # front → "Ana"
x = coada.pop(0)      # dequeue → scoate "Ana"

print(coada)          # ['Bogdan', 'Carla']

append() la spate, pop(0) din față → comportament FIFO.

🤔 Listă, Stivă sau Coadă — ce aleg?

StructurăRegula de accesAdaugScotFolosesc când...
Listă (acces direct)oriunde, prin indexoriundede oriundeam nevoie de acces direct la orice poziție (ex. al 5-lea elev din catalog)
Stivă (LIFO)doar din vârfîn vârfdin vârfcontează ultima acțiune: undo, „înapoi”, evaluarea expresiilor
Coadă (FIFO)doar prin capeteîn spatedin fațăcontează ordinea sosirii: cereri de suport, tipărire, semafor

Alegerea structurii potrivite depinde de ordinea în care trebuie procesate datele, nu de tipul lor.
