TEORIE

Ce înseamnă sortarea?

Definiție Sortarea (ordonarea) este procesul de aranjare a elementelor unei liste într-o ordine bine definită — crescătoare sau descrescătoare. Este una dintre operațiile fundamentale în informatică, prezentă în cataloage, clasamente, motoare de căutare și orice aplicație care gestionează date.

Vom studia trei metode de sortare, fiecare cu caracteristici, avantaje și domenii de aplicare distincte:

Metoda Idee principală Când este eficientă Complexitate
Selecția minimului Găsește minimul și îl plasează pe poziția corectă Liste mici, scop didactic O(n²)
Metoda bulelor Compară vecini și îi interschimbă dacă e nevoie Liste aproape sortate O(n²) / O(n)*
Sortare cu frecvențe Numără aparițiile fiecărei valori posibile Valori întregi într-un interval mic O(n + k)
Notația O( ) — complexitate O(n²) înseamnă că pentru n=100 elemente se fac ~10.000 operații. O(n+k) este mult mai rapid când k (intervalul valorilor) este mic. *Metoda bulelor devine O(n) cu optimizare de oprire timpurie, pe liste deja sortate.
1

Selecția minimului

La fiecare pas i, căutăm minimul din subșirul nesortat (pozițiile i..n-1) și îl plasăm pe poziția i prin interschimbare. Elementele de la 0 la i-1 sunt deja sortate.

1
Pornești de la poziția i = 0

Considerăm tot șirul nesortat. Bariera „sortat | nesortat" începe de la stânga.

2
Găsești minimul din pozițiile i..n-1

Parcurgi elementele rămase și rețin poziția celui mai mic element.

3
Interschimbi minimul cu elementul de pe poziția i

Dacă minimul nu este deja pe poziția i, realizezi interschimbarea.

4
Crești i cu 1 și repeți

Continuă până când i ajunge la n-2. Ultimul element este automat pe loc.

Urmărire vizuală — selecția minimului pe [64, 25, 12, 22, 11]

Celulele verde = deja sortate · portocaliu = minimul selectat la acest pas

Implementare în Python

selectia_minimului.pypython
def selectia_minimului(lista):
    n = len(lista)
    for i in range(n - 1):         # i = pozitia de umplut (bariera)
        poz_min = i                  # presupunem că minimul e deja la poz i
        for j in range(i + 1, n):   # căutăm minimul real în restul listei
            if lista[j] < lista[poz_min]:
                poz_min = j
        if poz_min != i:             # interschimbare doar dacă e necesar
            lista[i], lista[poz_min] = lista[poz_min], lista[i]
    return lista

note = [64, 25, 12, 22, 11]
print(selectia_minimului(note.copy()))  # [11, 12, 22, 25, 64]
Atenție — modificare in-place Funcția modifică lista originală (in-place). Dacă vrei să păstrezi lista originală neschimbată, transmite o copie: selectia_minimului(lista.copy())
2

Metoda bulelor (Bubble Sort)

Se compară elementele adiacente (vecine) și se interschimbă dacă sunt în ordine greșită. După fiecare parcurgere completă, cel mai mare element „urcă" la final — ca o bulă. Se repetă până nu mai apar interschimbări.

1
Pornești o parcurgere de la începutul listei

Compari perechile adiacente: lista[j] și lista[j+1].

2
Interschimbi dacă sunt în ordine greșită

Dacă lista[j] > lista[j+1], le schimbi între ele.

3
Ultimele i elemente sunt deja sortate

Le ignorăm la parcurgerea următoare — reducem zona de lucru.

4
Oprire timpurie: dacă nu s-a făcut nicio interschimbare

Lista este deja sortată! Această optimizare poate reduce mult numărul de pași.

Urmărire vizuală — prima parcurgere pe [5, 3, 8, 1, 4]

Celulele galbene = pereche comparată · verde = ajuns la locul final

Comparație j Valorile comparate Interschimb? Lista după comparație
j = 0 5 > 3 ✓ DA [3, 5, 8, 1, 4]
j = 1 5 < 8 ✗ NU [3, 5, 8, 1, 4]
j = 2 8 > 1 ✓ DA [3, 5, 1, 8, 4]
j = 3 8 > 4 ✓ DA [3, 5, 1, 4, 8]
Rezultat P1 → [3, 5, 1, 4, 8] — 8 a „urcat" la final ✓

Implementare în Python (cu optimizare de oprire timpurie)

metoda_bulelor.pypython
def metoda_bulelor(lista):
    n = len(lista)
    for i in range(n - 1):            # i = câte elemente sunt sortate la final
        schimb_facut = False
        for j in range(n - 1 - i):    # ignorăm ultimele i poziții (deja sortate)
            if lista[j] > lista[j + 1]:
                lista[j], lista[j+1] = lista[j+1], lista[j]
                schimb_facut = True
        if not schimb_facut:            # nicio interschimbare → lista deja sortată!
            break
    return lista

punctaje = [5, 3, 8, 1, 4]
print(metoda_bulelor(punctaje.copy()))  # [1, 3, 4, 5, 8]
3

Sortarea cu listă de frecvențe

În loc să comparăm elementele între ele, numărăm de câte ori apare fiecare valoare posibilă. Apoi reconstruim lista sortată adăugând fiecare valoare de câte ori apare. Funcționează exclusiv cu numere întregi dintr-un interval cunoscut și limitat.

1
Determină intervalul valorilor

Găsește valoarea minimă și maximă din listă cu min() și max().

2
Construiește lista de frecvențe

Creează o listă cu zerouri de lungime (max - min + 1). Pentru fiecare element x, crește frecventa[x - min] cu 1.

3
Reconstruiește lista sortată

Parcurge lista de frecvențe și adaugă valoarea v + min de frecventa[v] ori în lista rezultat.

Vizualizare — note la test: [7, 5, 9, 7, 10, 5, 8, 7]

Valoare (notă) 5 6 7 8 9 10
Frecvență 2 0 3 1 1 1
Contribuție la rezultat 5, 5 — 7, 7, 7 8 9 10
Lista sortată finală: [5, 5, 7, 7, 7, 8, 9, 10]

Implementare în Python

sortare_frecvente.pypython
def sortare_frecvente(lista):
    if not lista:
        return []
    minim = min(lista)
    maxim = max(lista)
    frecventa = [0] * (maxim - minim + 1)  # listă de zerouri
    for x in lista:
        frecventa[x - minim] += 1            # numărăm aparițiile
    rezultat = []
    for v, freq in enumerate(frecventa):
        rezultat.extend([v + minim] * freq)  # adăugăm de 'freq' ori valoarea
    return rezultat

note = [7, 5, 9, 7, 10, 5, 8, 7]
print(sortare_frecvente(note))  # [5, 5, 7, 7, 7, 8, 9, 10]
Limitare importantă Această metodă funcționează doar cu numere întregi și este eficientă când intervalul (max − min) este mic. Nu funcționează cu numere reale sau șiruri de caractere.

def bule_descrescator(lista):
    n = len(lista)
    for i in range(n - 1):
        schimb = False
        for j in range(n - 1 - i):
            if lista[j] < lista[j + 1]:  # < pentru ordine descrescătoare
                lista[j], lista[j+1] = lista[j+1], lista[j]
                schimb = True
        if not schimb:
            break
    return lista

inaltime = [165, 172, 158, 180, 163]
sortate = bule_descrescator(inaltime.copy())
print("Sortate descrescător:", sortate)  # [180, 172, 165, 163, 158]
for loc, h in enumerate(sortate[:3], 1):
    print(f"Locul {loc}: {h} cm")

Exemplul 3 — Sortare cu frecvențe: catalog clasă

Notele clasei a IX-A: [8, 6, 10, 7, 8, 6, 9, 7, 8, 10, 5, 7]. Sortează și generează un raport complet.

exemplu3_catalog.pypython
def sortare_frecvente(lista):
    if not lista: return []
    minim, maxim = min(lista), max(lista)
    freq = [0] * (maxim - minim + 1)
    for x in lista:
        freq[x - minim] += 1
    rezultat = []
    for v, f in enumerate(freq):
        rezultat.extend([v + minim] * f)
    return rezultat, freq, minim

note = [8, 6, 10, 7, 8, 6, 9, 7, 8, 10, 5, 7]
sortate, freq, minim = sortare_frecvente(note)
print("Note sortate:", sortate)
print(f"Media: {round(sum(note)/len(note), 2)}")
print("Distribuție note:")
for i, f in enumerate(freq):
    if f > 0:
        print(f"  Nota {i + minim}: {f} elev(i)")

Exercițiul 6 — Soluție (15 puncte)

Eroarea 1 — linia 3: range(n) → CORECT: range(n - 1)
Motivare: când i = n-1, bucla interioară nu mai are niciun element de parcurs (range(n, n) este goală), dar interschimbul lst[i], lst[poz_min] s-ar executa cu lst[i] = lst[i] — operație inutilă. Mai grav, în unele variante aceasta poate cauza indexare greșită. Ultimul element este automat pe locul corect.

Eroarea 2 — linia 5: range(i, n) → CORECT: range(i + 1, n)
Motivare: dacă j pornește de la i, elementul de pe poziția i se compară cu el însuși. poz_min rămâne i, deci nu se face interschimb — dar în cel mai rău caz poate masca o valoare mai mică. Corect: căutarea minimului trebuie să înceapă de la i+1.

def selectia_corecta(lst): n = len(lst) for i in range(n - 1): # FIX 1: range(n-1), nu range(n) poz_min = i for j in range(i + 1, n): # FIX 2: range(i+1, n), nu range(i, n) if lst[j] < lst[poz_min]: poz_min = j if poz_min != i: lst[i], lst[poz_min] = lst[poz_min], lst[i] return lst
