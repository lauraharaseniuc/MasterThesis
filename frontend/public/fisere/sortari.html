De ce sortăm datele?

A sorta o listă înseamnă a-i aranja elementele într-o anumită ordine (crescătoare sau descrescătoare). Sortarea apare peste tot: clasamentul unui concurs, ordonarea notelor unei clase, afișarea produselor după preț, triajul pacienților dintr-o urgență după gravitate.

În clasa a IX-a studiem trei metode clasice. Toate produc același rezultat, dar diferă prin numărul de comparări și de interschimbări — adică prin eficiență. Folosește vizualizatorul de mai jos ca să vezi pas cu pas cum „gândește” fiecare algoritm.

1. Sortarea prin selecția minimului

Ideea

Parcurgem lista, găsim cel mai mic element și îl aducem pe prima poziție. Apoi căutăm minimul din rest și îl punem pe poziția a doua, și tot așa. La fiecare pas, partea din stânga devine definitiv sortată.

Analogie din viața reală Aranjarea finaliștilor unui concurs de talente în ordinea crescătoare a scorului: scoți de fiecare dată concurentul cu cel mai mic scor rămas și îl așezi la coadă.

Cod Python

def sortare_selectie(v):
    n = len(v)
    for i in range(n - 1):
        poz_min = i
        for j in range(i + 1, n):
            if v[j] < v[poz_min]:
                poz_min = j
        v[i], v[poz_min] = v[poz_min], v[i]   # interschimbare
    return v

print(sortare_selectie([5, 2, 9, 1, 7]))   # [1, 2, 5, 7, 9]

Observație: face multe comparări, dar puține interschimbări (cel mult una pe pas).

2. Metoda bulelor (bubble sort)

Ideea

Comparăm mereu elemente vecine și le interschimbăm dacă sunt în ordine greșită. Repetăm parcurgerile până nu mai facem nicio interschimbare. La fiecare trecere, cel mai mare element „urcă” ca o bulă până la capăt.

Analogie din viața reală Ordonarea elevilor unei clase după înălțime: compari fiecare doi colegi vecini din rând și îi rogi să facă schimb de locuri dacă cel mai înalt stă în fața celui mai scund.

Cod Python

def sortare_bule(v):
    n = len(v)
    for i in range(n - 1):
        schimbat = False
        for j in range(n - 1 - i):
            if v[j] > v[j + 1]:
                v[j], v[j + 1] = v[j + 1], v[j]
                schimbat = True
        if not schimbat:        # lista e deja sortată → ne oprim
            break
    return v

Observație: cu „steagul” schimbat devine foarte rapidă pe liste aproape sortate.

3. Sortarea cu listă de frecvențe (counting sort)

Ideea

Folosită când valorile sunt numere întregi dintr-un interval mic (ex. note de la 1 la 10). Nu comparăm elemente! Numărăm de câte ori apare fiecare valoare într-o listă de frecvențe, apoi reconstruim lista sortată parcurgând frecvențele de la mic la mare.

Analogie din viața reală Triajul pacienților după gravitate (cod 1–5) sau ordonarea notelor unui test (1–10): numeri câți sunt de fiecare cod, apoi îi „strigi” în ordine.

Cod Python

def sortare_frecvente(v, vmax=10):
    frecv = [0] * (vmax + 1)     # frecv[k] = de câte ori apare k
    for x in v:
        frecv[x] += 1
    rezultat = []
    for k in range(vmax + 1):
        rezultat += [k] * frecv[k]      # adaug valoarea k de frecv[k] ori
    return rezultat

print(sortare_frecvente([7, 3, 7, 1, 3, 10]))   # [1, 3, 3, 7, 7, 10]

Observație: foarte rapidă (nu face comparări), dar are nevoie de memorie pentru lista de frecvențe și funcționează doar pe numere întregi dintr-un interval cunoscut.
