Operații cu cifrele unui număr

Idei cheie Orice număr natural poate fi descompus cifră cu cifră prin împărțiri succesive la 10. Cifra unităților unui număr n se obține cu n % 10, iar restul numărului (fără ultima cifră) se obține cu n // 10.
A

Accesul la cifrele unui număr

Pentru a parcurge cifrele lui n = 4753 de la dreapta la stânga:

4mii
7sute
5zeci
3unități
1
Extrage cifra unităților

cifra = n % 10 → 4753 % 10 = 3

2
Elimină cifra unităților

n = n // 10 → 4753 // 10 = 475

3
Repetă până când n = 0

Condiție de oprire: while n != 0

pythonparcurgere_cifre.py
n = 4753
while n != 0:
    cifra = n % 10
    print(cifra)
    n = n // 10
Caz special: n = 0 Dacă n = 0, bucla while n != 0 nu se execută deloc! Trateaza separat cazul în care numărul este 0.

Divizori și multipli

Definiție d este divizor al lui n dacă n % d == 0 (împărțirea este exactă, restul este 0). Echivalent, n este multiplu al lui d.
C

Parcurgerea divizorilor unui număr

Există trei strategii pentru a găsi toți divizorii lui n = 36:

Strategie Interval parcurs Număr de pași (n=36) Complexitate
1. De la 1 la n range(1, n+1) 36 pași O(n)
2. De la 1 la n//2 range(1, n//2+1) + n 18 pași O(n/2)
3. De la 1 la √n range(1, int(n**0.5)+1) 6 pași O(√n)
pythondivizori_sqrt.py — varianta eficientă O(√n)
import math

def divizori(n):
    divs = []
    for d in range(1, int(math.sqrt(n)) + 1):
        if n % d == 0:
            divs.append(d)
            if d != n // d:
                divs.append(n // d)
    divs.sort()
    return divs

print(divizori(36))
De ce funcționează varianta cu √n? Dacă d divide n, atunci și n // d divide n. Perechile de divizori sunt simetrice față de √n, deci este suficient să căutăm până la √n și să adăugăm ambii din pereche.
3

Algoritmul lui Euclid (cmmdc)

Definiție CMMDC(a, b) = cel mai mare număr natural care divide simultan atât pe a, cât și pe b. Exemplu: CMMDC(48, 18) = 6, deoarece 6 | 48 și 6 | 18, și nu există un număr mai mare cu această proprietate.
D

Algoritmul lui Euclid cu scăderi repetate

Principiu: dacă a ≠ b, scade cel mai mic din cel mai mare. Repetă până când a = b. Acel valoare este CMMDC.

Exemplu: CMMDC(48, 18)

a=48, b=18→ a > b → a = 48 − 18 = 30
a=30, b=18→ a > b → a = 30 − 18 = 12
a=12, b=18→ b > a → b = 18 − 12 = 6
a=12, b=6→ a > b → a = 12 − 6 = 6
a=6, b=6→ a = b → CMMDC = 6
python
def cmmdc_scaderi(a, b):
    while a != b:
        if a > b:
            a = a - b
        else:
            b = b - a
    return a

print(cmmdc_scaderi(48, 18))
Dezavantaj: Poate fi foarte lent dacă numerele sunt foarte diferite (ex.: CMMDC(1000000, 1) necesită 999999 scăderi!).
E

Algoritmul lui Euclid cu împărțiri repetate

Principiu: înlocuiește (a, b) cu (b, a % b). Repetă până când b = 0. Rezultatul este a.

Exemplu: CMMDC(48, 18)

a=48, b=18→ 48 % 18 = 12 → (18, 12)
a=18, b=12→ 18 % 12 = 6 → (12, 6)
a=12, b=6→ 12 % 6 = 0 → (6, 0)
a=6, b=0→ b = 0 → CMMDC = 6

​

python
def cmmdc_impartiri(a, b):
    while b != 0:
        a, b = b, a % b
    return a

print(cmmdc_impartiri(48, 18))
Avantaj: Mult mai eficient! Converge în O(log(min(a,b))) pași. Exemplul de mai sus s-a rezolvat în 3 pași față de 5 pași cu scăderi.
F

Aplicație: CMMMC pe baza CMMDC

Cel mai mic multiplu comun (CMMMC) se calculează cu formula: cmmmc(a,b) = (a * b) // cmmdc(a, b)

pythoncmmmc.py
def cmmdc(a, b):
    while b != 0:
        a, b = b, a % b
    return a

def cmmmc(a, b):
    return (a * b) // cmmdc(a, b)

print(cmmmc(4, 6))
print(cmmmc(12, 18))

Descompunerea în factori primi

Principiu Orice număr natural > 1 se poate scrie unic ca produs de numere prime: 360 = 2³ × 3² × 5. Algoritmul împarte repetat n la cel mai mic factor prim care îl divide, pornind de la 2.
G

Algoritmul de factorizare

Exemplu: Descompunerea lui 360

n Factor d n % d == 0? Putere n după împărțire
360 2 DA 2¹ 180
180 2 DA 2² 90
90 2 DA 2³ 45
45 2 NU — 45 (d creste la 3)
45 3 DA 3¹ 15
15 3 DA 3² 5
5 3 NU — 5 (d creste la 4, 5)
5 5 DA 5¹ 1 → STOP

Rezultat: 360 = 2³ × 3² × 5

pythonfactorizare.py
def factorizare(n):
    d = 2
    while d * d <= n:
        while n % d == 0:
            print(f"{d}", end=" ")
            n //= d
        d += 1
    if n > 1:
        print(f"{n}", end=" ")
    print()

factorizare(360)
Optimizare: d * d <= n Nu este necesar să verificăm factori mai mari decât √n, deoarece dacă n mai are un factor prim rămas după parcurgere, acesta va fi > √n și va apărea ca rest — tratat de if n > 1.

Exercițiul 6 — Soluție (15 puncte)

Eroarea 1 — linia 4: b = a - b → CORECT: a = a - b
Motivare: când a > b trebuie să micșorăm pe a (cel mai mare), nu pe b. Codul greșit modifică b în loc de a, ducând la rezultate eronate.

Eroarea 2 — linia 6: a = b - a → CORECT: b = b - a
Motivare: în ramura else, b ≥ a, deci trebuie să micșorăm pe b. Codul greșit modifică a, inversând logica algoritmului.

Eroarea 3 — linia 13: n = n // 100 → CORECT: n = n // 10
Motivare: pentru a avansa la cifra următoare, eliminăm o singură cifră (împărțim la 10). Împărțind la 100 sărim peste câte două cifre, obținând suma doar pentru cifrele de pe pozițiile impare.

def cmmdc_corect(a, b): while a != b: if a > b: a = a - b else: b = b - a return a def suma_cifre_corecta(n): s = 0 while n > 0: cifra = n % 10 s = s + cifra n = n // 10 return s

Punctaj: (3p identificare + 2p explicație) × 3 erori = 15p.
